## 2. 정한 것

| # | 무엇 | 정한 값 | 까닭 |
|---|---|---|---|
| T1 | 기준의 글 | 모든 식 · 한계 · 적용 범위는 이 세션에서 연 AISI S100-16 의 글(`aisi-cold-formed-steel` 스킬의 규정 · 해설 · 설계 매뉴얼 예제)에서만. 확인하지 못한 것은 넣지 않고 알린다 | 값을 지어내지 않는다 |
| T2 | 구멍이 있는 부재의 탄성 좌굴 | 기준 부록 2 가 허용하는 방법 그대로 — 전체 좌굴은 길이로 가중 평균한 단면 성질, 국부는 구멍 없는 단면과 구멍 자리의 순단면 가운데 작은 것, 뒤틀림은 구멍 구간에서 줄인 웹 두께(식은 스킬에서 확인) — 를 이 프로그램의 FSM 으로 | 유한요소 해석 없이 기준이 인정하는 길 |
| T3 | 적용 범위 밖 | 기준의 한계(구멍 크기 · 간격 · 위치 · 단면 종류 등)를 벗어나면 그 조항은 「평가하지 못함」 과 까닭 — 한계를 넘는 값을 말없이 계산하지 않는다. 웹을 가려낼 수 없는 단면(직접 그린 단면 등)도 같다 | 이 프로젝트의 규칙 |
| T4 | 입력이 없을 때 | 구멍 · 보강재 · 비틀림 입력이 없으면 지금의 결과와 바이트까지 같다. 구멍이 없다고 밝힌 것과 입력하지 않은 것을 가르지 않는다(지금처럼 범위 고지는 남는다 — 「구멍 없는 부재로 계산」) | 있던 결과를 바꾸지 않는다 |
| T5 | §H4 의 비틀림 응력 | 두 길: ① 사람(또는 AI)이 그 점의 휨 응력 · 비틀림 뒤틀림 응력을 직접 준다 ② 하중의 편심으로 계산 — 닫힌 식을 원문 · 교과서 식으로 확인할 수 있는 경우만(비틀림 단순 지지의 한 경간: 등분포 · 중앙 집중). 그 밖의 지지 조건은 ① 로 | 비틀림 해석 전체를 넣는 일이 아니다 |
| T6 | 자동 계산 종류(퍼린 · 장선 · 거트 · 스터드) | 구멍과 보강재는 구간 검토에 그대로 전한다(천공 스터드가 흔한 쓰임이다). §H4 는 직접 입력 모드의 휨 · 조합에만 | 사슬의 하중 해석은 비틀림을 풀지 않는다 |
| T7 | 화면의 자리 | 편집 화면(끼운 설계 화면)의 설계 탭에 접이 구역 셋 — 「웹 구멍(천공)」 · 「횡방향 웹 보강재」 · 「비틀림(§H4)」. 처음 값은 모두 「없음」 | 관련 칸(전단 · 웹 크리플링) 가까이 |
