## 4. 단계별 기록

### EA — 엔진: 구멍이 있는 부재(끝, 커밋 `1ec6c4f`)

출처는 모두 `aisi-cold-formed-steel` 스킬(E · F장, 부록 2, 해설 부록 2 의 2.2.6 · 2.3.2 · 2.3.4, 설계 매뉴얼 II-14 · III-4).

- **순단면.** 웹(역할이 `web` 인 요소)의 구멍 가장자리에 절점을 끼우고 깊이 dh 의 띠를 두께 1e-6·t 로 둔다(이음은 그대로 — CUFSM 이 두께 0 으로 하는 것과 같다). Anet · Sfnet · Inet · Jnet · xo,net · Cw,net 이 그 모델에서 나온다. 국부 해석에서는 그 띠를 지운다.
- **전체(§E2.5 · §F2.2).** 표 2.3.2-1 의 가중 평균을 있던 Fcre 식에(식 2.3.2.1.1-1, 2.3.2.1.2-1 – 4, 2.3.2.1.3, 2.3.4.1.1-1, 2.3.4.1.2-1). 뒤틀림 성질은 Cw,net. 비지지 길이 안의 구멍 수는 n = floor((L − Lh)/s) + 1(III-4 의 96 in 에 넷 · 48 in 에 둘이 나온다).
- **국부(§E3.2.2 · §F3.2.2).** Pcrℓ = min(구멍 없는 단면, 순단면)(해설 식 C-2.2.6-1) — 순단면의 값은 반파장 ≤ Lh 의 FSM 극소. 강도의 상한 Pynet = Anet·Fy · Mynet = Sfnet·Fy(식 E3.2.2-1/-2, F3.2.2-1/-2). §H2 · §H3 이 쓰는 국부 강도에도 같은 상한.
- **뒤틀림(§E4.2 · §F4.2).** 웹 두께 tr = t(1 − Lh/Lcrd)^(1/3)(식 2.3.2.3-1 / 2.3.4.3-1) — 구멍 없는 값이 FSM 에서 왔으면 그 Lcrd 에서만 FSM 을 다시(기준 하중은 줄인 단면에 — 매뉴얼 II-14 의 20.5 kip-in 이 그렇게만 나온다), 부록 2 의 식에서 왔으면 그 식의 웹 항에. 강도는 전이 구간의 식(E4.2-1/-2, F4.2-1/-2).
- **쓰이는 곳.** 압축 · 휨(정모멘트 구간 포함) · 조합(§H1.2) · 길이가 빈 때의 하한. 검토의 id 는 그대로이고 구멍이 있으면 `clause_variant: 'holes'` 와 그 조항. 구멍이 있으면 비탄성 여유(§F2.4 · §F3.2.3 · §F4.3)는 끈다(구멍의 글이 없다 — 경고).
- **한계(밖이면 「평가하지 못함」 — 구멍 없는 값은 참고로만).** 단면은 C · Z · 트랙만(해설: 웹에 구멍이 있는 립 C 로 맞춘 조항), 웹을 가려낼 수 있을 것(역할이 있는 모델의 곧은 한 판), 구멍이 평평한 웹 안에, 가장자리를 보강한 구멍은 아님(해설 2.2.6), 뒤틀림은 Lh < Lcrd 이고 s ≥ Lcrd(뒤는 에이전트의 읽기 — 식 2.3.2.3-1 은 반파장에 구멍 하나를 본다), 구멍은 웹의 가운데(치우친 구멍의 비대칭 순단면 2.3.2.1.4 는 없다), §I6.2.1 의 양압 R · 랩 구간에는 글이 없다.
- **맞대 본 값.** II-14: 매뉴얼의 탄성값으로 Mnℓ · Mnd · Mn = 12.4 · 14.7 · 12.4(같다), 우리 FSM 으로 Mcrℓh 9.55(9.60) · Mcrd 23.31 → 20.5(23.4 → 20.5). III-4: Fcre 39.63(39.5) · Pne 7.61(7.62) · Pnℓ 3.52 · Pynet 9.08 · tr 0.0317 · Pnd 5.96(5.98). 전이 구간의 식은 두 예제가 지나지 않아 손계산으로.
- **하지 않은 것.** 무늬진 구멍(식 2.3.2.3-2), 치우친 구멍, B1 증폭의 구멍(글이 없다).
