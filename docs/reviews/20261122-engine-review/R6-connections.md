# R6 — 접합부 (AISI S100-16 Chapter J) · Lap 접합

## 요약

발견사항 수: **P0 2 · P1 12 · P2 9 · P3 1** (총 24)

볼트(J3)·나사(J4)의 기본 식과 φ/Ω, J6 의 Table J6-1 계수, J6.1·J6.2(평판)·J6.3(1열 패턴) 식은 매뉴얼 예제 IV-9·IV-11·IV-12 와 맞는다. 문제는 세 가지다. 첫째, **용접 접합에는 J6 파단이 아예 없다**. 그런데도 `verification_complete=True`, `pass=True` 를 낸다. 매뉴얼 IV-2(아크 스팟)는 블록전단이 지배하는데, 도구는 이를 64 % 과대평가하고 PASS 로 판정한다. 둘째, 식 자체가 틀린 곳이 여럿이다. 필릿 용접의 L/t 분기와 φ/Ω 선택(t1>t2 면 +20 %), 아크 스팟 식 J2.2.2.1-3(√ 오용, 최대 +15 %), 아크 시임(d_a 대신 d, Ω, L≤3d), PAF 전단 풀아웃(E 대신 66 ksi 를 써서 1/58 로 계산됨), PAF 와셔 상한(0.875 in, 기준은 0.60 in), d<1/2 in 볼트의 Fnv(0.45Fu, 기준은 0.40Fu)가 그렇다. 셋째, **하중 방향을 구분하지 않는다**. 전단 한계상태와 인장 한계상태를 하나의 min() 으로 묶는데, 인장 쪽 한계상태(나사 Pnts, PAF Pntp, 아크 스팟 J2.2.3)는 빠져 있고 J4.5·J2.2.4·J5.4 조합 검토도 없다. 볼트 J3.4 상호작용이 비율 1.51 로 실패해도 최종 판정은 PASS 다.

Lap 접합(`lap_connection.py`)의 패스너 수요 모델(`max(Mu/(d−t), Vu)` 를 모든 패스너가 균등 분담)은 기준에 근거가 없는 사내 가정이다. 이 가정대로라면 플랜지 우력을 받는 각 행이 플랜지력 전체를 받아야 한다. 따라서 이 가정과도 맞지 않아, 패스너당 수요를 n_rows 배(예제에서 2배) 과소평가할 수 있다(의심). 또 Se 가 없어 휨을 검토하지 않았어도 `pass=True` 를 낸다. MCP `design_lap_connection` 은 Se·Mnd·Vn·design_method·end_distance 를 아예 받지 않는다.

## 발견사항

### R6-01 [P0] [확인] 용접 접합에 J6 파단 검토가 없는데도 "검토 완결 · PASS" 로 판정한다
