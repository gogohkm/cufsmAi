# R7 — 하중·연속보 해석·소요강도·브레이싱 (`python/design/loads/`)

## 요약

발견사항 수: **P0 4 · P1 13 · P2 8 · P3 4** (총 29).

보 해석 핵심(3-모멘트법·직접강성 FE)은 닫힌 해와 맞는다: 단순보·2/3/4 등경간·부등경간·고정단·캔틸레버·내민보의 지점모멘트·반력·처짐이 독립 강성법 해와 유효숫자 4자리까지 같고, 독립 해는 AISI 설계매뉴얼 Example II-2A(랩·부재 두께 차이 포함)의 활하중 도표값(7.61 / 4.44 / 4.04 / 3.38 / 1.94 / 3.24 / 4.30 kip-ft, R 1.05 / 2.93 / 2.24 kips)을 그대로 재현했다. 문제는 해석 결과를 **설계 입력으로 바꾸는 층**에 몰려 있다.

- 하중조합: `L` 이 없으면 `L` 이 들어간 조합 전체가 빠진다. 그래서 지붕 퍼린의 대표 조합 LRFD 1.2D+1.0W+0.5Lr, ASD D+0.75(0.6W)+0.75Lr 이 계산되지 않는다(정압 풍하중에서 Mu 가 LRFD −11 %, ASD −28 %). 활하중·적설의 부분재하(ASCE 7 §4.3.3, §7.5)도 없다(내부경간 M+ −32 %).
- 양력: 바닥 플랜지가 압축되는 경간 중앙 영역 대신 지점 영역의 비지지길이를 쓴다(Lb 75 in vs 225 in). R 계수(I6.2.1)는 데크 종류를 보지 않는다(데크 없음·스탠딩심에도 R). 단면 정보가 없으면 R=0.60 으로 조용히 채운다(MCP `design_purlin` 은 항상 이 경로). 스탠딩심 지붕을 중력에서 연속 횡지지로 본다(App. A I6.2.2 위반).
- 데크 회전강성 kφ: Gao & Moen 식의 항이 빠져 Example II-1C 값의 1.72 배(0.194 vs 0.113)가 나온다.
- 랩: 임계위치·비지지길이 계산에서 좌/우 랩 길이가 FE·UI 규약과 뒤바뀌었다. FE 반력의 부호를 버린다(`abs`). 자유단(N)이 있으면 반력과 지점의 대응이 한 칸씩 밀린다. `laps` 사전만 주는 경로(MCP)에서는 랩 강성이 해석에 반영되지 않는다(랩 끝 M −19 %).
- 내민보 구간의 부모멘트 비지지 영역이 빠진다. 데크가 없으면 정모멘트 영역 중 첫 번째만 쓴다. `cantilever`·`cont-n` 이 조용히 단순보·1경간이 된다.

Appendix 2 해석식(2.3.1.3, 2.3.3.3)과 표 2.3.1.3-1 은 원문과 한 줄씩 대조해 맞다. FSM 대비 휨 왜곡좌굴 Fcrd 비는 0.87 – 0.92(보수측)다. 다만 실제 호출자(`aisi_s100.py`)는 평탄폭을 넘긴다. 이 함수 계약은 외-외 ho 와 중심선 b, d 다. 그래서 국부좌굴 판식은 코너를 두 번 빼고(Fcrl +8 – 15 %), Z 의 왜곡좌굴은 +9 – 13 % 가 되어 θ=50° 에서는 FSM 을 넘는다(1.037).

### R7-01 [P0] [확인] `L` 이 없으면 W 를 포함한 주요 조합이 통째로 빠짐 (LRFD 4, ASD 6, LRFD 1.2D+1.0W)

### R7-02 [P0] [확인] 양력 설계의 비지지길이가 경간 중앙(하부 플랜지 압축)이 아니라 지점 근처 영역에서 온다
- 위치: `python/design/loads/required_strength.py:286-354`. 호출자 `src/webview/StcfsdPanel.ts:2030-2061`.
- 현상: 양력 M 을 부호 반전(`uM_flipped`)한 뒤 중력 로직을 그대로 돌린다. 반전 후 "negative_regions" 는 여전히 내부지점 ± (랩 끝 → 변곡점) 구간이다. 실제 양력에서 그곳은 상부 플랜지 압축(데크 지지) 영역이다. 정작 하부 플랜지가 압축되는 경간 중앙(I6.2.1 적용 영역)은 반전 후 "positive_region" 이 되어 데크가 있으면 `braced: True, Ly 0` 이 된다. `design_purlin` 은 `uplift_bracing.negative_region.Ly_in` 을 양력 설계 Lb 로 넘긴다(주석도 "경간 중앙이 하부 압축"이라고 잘못 가정한다).

- 회귀 시험: 2경간 25 ft, D=10, W=−150 plf, LRFD, d=14 → 양력 비지지 영역 0 – 18.75 ft, Ly 225 in, 해당 |Mu| = 6.195 kip-ft(현재 출력값과 같음).

### R7-06 [P1] [확인] 데크 회전강성 kφ 식에 항이 빠져 1.72 배 과대, t_panel 무시
- 위치: `python/design/loads/bracing.py:20-58`
- 현상: 구현은 `kphi = 1/(1/(k c²) + c³/(3EIc²))` 이고, 원식(Example II-1C, Gao & Moen 2011)은 `kφ = 1/(1/(kc²) + (b²c/2 + bc² + c³/3)/(EIc²))` 이다. b²c/2 + bc² 항이 없다. k 는 c 와 무관하게 1.77 kip/in 로 고정되어 있다(원식 k = 1.934 c^-0.4). `t_panel` 인수는 쓰이지 않는다. docstring 의 "Chen & Moen" 도 출처가 틀렸다.
- 근거: Example II-1C 3b(`data/beam-design/examples/Example_II_1C…md:144-170`): b = c = 1.25, k = 1.77/12, I = 0.059³/12 → **0.113**. 엔진 `calc_rotational_stiffness(0.0179, 0.059, 12, 2.5)` = **0.1936**(+72 %). flange 3.5 in → 0.297. t_panel 0.030 → 0.1936(무변). 스크립트 `t7_misc.py`.
- 영향: 정모멘트 FSM(데크 스프링)과 왜곡좌굴 해석식 kφ 가 과대 → Mcrd·Mnd 가 비안전측이다(II-5 단면 예: Fcrd (0.445+0.194)/0.00958 = 66.7 vs 58.2 ksi, +15 %). 회귀 시험 `test_deck_stiffness` 는 0.05 – 0.50 범위만 봐서 못 잡는다.
- 수정안: 원식대로 구현한다. b = 웹–나사 거리, c = 립–나사 거리(입력, 기본 B/2), k = 1.934·c^-0.4 / s(0.018 in 패널 기준. t_panel < 0.018 또는 리브에서 1 in 초과면 경고), I = t_purlin³/12. 원식이 패널 두께를 쓰지 않는다는 점을 명시한다.
- 회귀 시험: (0.0179, 0.059, 12, 2.5) → 0.113 ± 1 %.
